# Planes del Grupo 🎲

App para sortear actividades semanales en grupo, con puntuación y ranking.

## Cómo subir a GitHub Pages (paso a paso)

### 1. Crea el repositorio en GitHub
1. Ve a [github.com](https://github.com) e inicia sesión
2. Pulsa el botón verde **"New"** (arriba a la izquierda)
3. Ponle nombre: `planes-grupo`
4. Marca **"Public"**
5. Pulsa **"Create repository"**

### 2. Sube los archivos
1. En la página del repositorio recién creado, pulsa **"uploading an existing file"**
2. Arrastra los 3 archivos de esta carpeta: `index.html`, `manifest.json`, `README.md`
3. Pulsa **"Commit changes"**

### 3. Activa GitHub Pages
1. Ve a **Settings** (en tu repositorio)
2. En el menú izquierdo busca **"Pages"**
3. En "Branch" selecciona **main** → carpeta **/ (root)**
4. Pulsa **Save**
5. En 1-2 minutos tendrás tu enlace: `https://tu-usuario.github.io/planes-grupo`

### 4. Configura Supabase para producción
1. Ve a tu proyecto en Supabase → **Authentication → URL Configuration**
2. En "Site URL" pon tu enlace de GitHub Pages
3. En "Redirect URLs" añade también el mismo enlace

## Instalar como app en el móvil

### Android (Chrome)
1. Abre el enlace en Chrome
2. Pulsa los 3 puntos → "Añadir a pantalla de inicio"

### iPhone (Safari)
1. Abre el enlace en Safari
2. Pulsa el botón compartir → "Añadir a pantalla de inicio"
